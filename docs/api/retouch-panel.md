# RetouchPanel

Brush controls and the parameters specific to one retouch kernel.

`import { RetouchPanel } from "glass-ux-image/tools/retouch"`

[Live examples](https://dastari.github.io/glass-ux-image/components/retouch-panel)

## Props

| Prop | Type | Valid options | Required | Default | Description |
| --- | --- | --- | --- | --- | --- |
| kind | `RetouchKind` | "brush", "eraser", "clone", "heal", "spot-heal", "patch", "blur", "sharpen", "smudge", "dodge", "burn", "sponge", "colour-replace", "red-eye", "liquify" | yes | — | Tool whose settings to edit. |

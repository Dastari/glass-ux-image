# ToolSettings

A tool's public Panel or collapsible Sections, independently of either editor composition.

`import { ToolSettings } from "glass-ux-image/editor"`

[Live examples](https://dastari.github.io/glass-ux-image/components/tool-settings)

## Props

| Prop | Type | Valid options | Required | Default | Description |
| --- | --- | --- | --- | --- | --- |
| tool | `ImageTool<any>` | See type | yes | — | Tool whose public panels should be shown. |

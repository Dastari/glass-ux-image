# TransformTarget

Target selector shared by the geometry tools.

`import { TransformTarget } from "glass-ux-image/tools/move"`

[Live examples](https://dastari.github.io/glass-ux-image/components/transform-target)

## Props

| Prop | Type | Valid options | Required | Default | Description |
| --- | --- | --- | --- | --- | --- |
| base | `boolean \| undefined` | false, true | no | true | Include the base picture as a selectable transform target. |

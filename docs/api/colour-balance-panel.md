# ColourBalancePanel

Shadow, midtone and highlight colour-balance wheels.

`import { ColourBalancePanel } from "glass-ux-image/tools/develop"`

[Live examples](https://dastari.github.io/glass-ux-image/components/colour-balance-panel)

## Props

| Prop | Type | Valid options | Required | Default | Description |
| --- | --- | --- | --- | --- | --- |
| editor | `EditorSession \| undefined` | See type | no | — | Explicit session; otherwise uses the nearest ImageEditorProvider. |

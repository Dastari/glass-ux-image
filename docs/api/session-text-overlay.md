# SessionTextOverlay

Click an existing glyph layer to edit it, or the stage to place a new one.

`import { SessionTextOverlay } from "glass-ux-image/tools/text"`

[Live examples](https://dastari.github.io/glass-ux-image/components/session-text-overlay)

## Props

| Prop | Type | Valid options | Required | Default | Description |
| --- | --- | --- | --- | --- | --- |
| session | `EditorSession \| undefined` | See type | no | — | Explicit session, or the nearest editor provider. |

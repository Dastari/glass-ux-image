# SessionTextPanel

Styling for the selected text, or defaults for the next text layer.

`import { SessionTextPanel } from "glass-ux-image/tools/text"`

[Live examples](https://dastari.github.io/glass-ux-image/components/session-text-panel)

## Props

| Prop | Type | Valid options | Required | Default | Description |
| --- | --- | --- | --- | --- | --- |
| session | `EditorSession \| undefined` | See type | no | — | Explicit session, or the nearest editor provider. |

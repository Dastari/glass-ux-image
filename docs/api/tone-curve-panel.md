# ToneCurvePanel

Session-bound RGB and per-channel tone curves.

`import { ToneCurvePanel } from "glass-ux-image/tools/develop"`

[Live examples](https://dastari.github.io/glass-ux-image/components/tone-curve-panel)

## Props

| Prop | Type | Valid options | Required | Default | Description |
| --- | --- | --- | --- | --- | --- |
| editor | `EditorSession \| undefined` | See type | no | — | Explicit session; otherwise uses the nearest ImageEditorProvider. |

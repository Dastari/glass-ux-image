# EffectsStackPanel

Duplicate effects can be reordered, blended, edited and removed with intercepted labelled actions.

`import { EffectsStackPanel } from "glass-ux-image/tools/effects"`

[Live examples](https://dastari.github.io/glass-ux-image/components/effects-stack-panel)

## Props

| Prop | Type | Valid options | Required | Default | Description |
| --- | --- | --- | --- | --- | --- |
| session | `EditorSession \| undefined` | See type | no | — | Session to edit; defaults to the nearest provider. |

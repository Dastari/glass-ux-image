# HslPanel

Eight colour ranges with smoothly overlapping hue, saturation and luminance adjustments.

`import { HslPanel } from "glass-ux-image/tools/develop"`

[Live examples](https://dastari.github.io/glass-ux-image/components/hsl-panel)

## Props

| Prop | Type | Valid options | Required | Default | Description |
| --- | --- | --- | --- | --- | --- |
| editor | `EditorSession \| undefined` | See type | no | — | Explicit session; otherwise uses the nearest ImageEditorProvider. |

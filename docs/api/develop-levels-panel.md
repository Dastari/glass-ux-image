# DevelopLevelsPanel

Session-bound master and per-channel levels.

`import { DevelopLevelsPanel } from "glass-ux-image/tools/develop"`

[Live examples](https://dastari.github.io/glass-ux-image/components/develop-levels-panel)

## Props

| Prop | Type | Valid options | Required | Default | Description |
| --- | --- | --- | --- | --- | --- |
| editor | `EditorSession \| undefined` | See type | no | — | Explicit session; otherwise uses the nearest ImageEditorProvider. |

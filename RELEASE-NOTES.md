# glass-ux-image 0.2.1

Updates Glass UX and the matching docs kit to 0.16.1, including the darker dark Flat canvas across all palettes. The demo and mock-ups use the same release.

```sh
pnpm add https://github.com/Dastari/glass-ux/releases/download/v0.16.1/glass-ux-0.16.1.tgz
pnpm add https://github.com/Dastari/glass-ux-image/releases/download/v0.2.1/glass-ux-image-0.2.1.tgz
```

[Documentation and full editor](https://dastari.github.io/glass-ux-image/).

## Assets

- `glass-ux-image-0.2.1.tgz`: the package.
- `glass-ux-image-docs.tar.gz`: the documentation site.
- `SHA256SUMS`: checksums for both archives.

Known limits remain as recorded in `PROPOSAL.md` under "0.2.0".

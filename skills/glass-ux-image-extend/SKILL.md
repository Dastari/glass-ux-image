---
name: glass-ux-image-extend
description: Add a tool, filter, warp or layer kind using the public Glass UX Image extension contracts.
---

Read docs/extensions.md, docs/headless.md and the generated API for the installed version.
A tool declares its panel, overlay and rendering parts. Session actions own committed edits.
A filter needs matching TypeScript and GLSL passes over linear premultiplied RGBA; add conformance
scenes without raising tolerance to hide a failure. A warp maps output to source before filters.
A layer kind supplies a TileSource and leaves positioning/blending to the session. Keep core and
filters free of DOM, React and Glass UX. Use messages, semantic tokens and keyboard alternatives
in UI. Run the package checks, docs checks and affected browser suites. SwiftShader is CPU
emulation, not evidence of real GPU speed.
